<StageMeta type="PaddleTextDetector" />

Runs only the detection model of a PaddleOCR preset. Use it when you want boxes
without paying for recognition, or to feed a different recognizer.

```ts
import { Pipeline } from '@stabrise/scaledp'
import { PdfToImage } from '@stabrise/scaledp/pdf'
import { PaddleTextDetector, TesseractRecognizer } from '@stabrise/scaledp/ocr'

const rows = await new Pipeline([
    new PdfToImage(),
    new PaddleTextDetector({ outputCol: 'boxes' }),
    new TesseractRecognizer({ inputCols: ['image', 'boxes'] }),
]).transform(file)
```

Regions are **line-level** — one box per line of text, as in Python ScaleDP.
Boxes are axis-aligned with `score: 1`; the confidence a recognizer produces is a
separate thing. `DetectorOutput.type` is `'paddle'`.

<Callout>
`PaddleTextRecognizer` detects *and* recognises in a single pass and ignores any
separate detector's boxes. Running both is how you compare what a detector finds
against what the recognizer acted on — it is not a way to feed one into the
other. For that, use [`TesseractRecognizer`](/docs/stages/recognise/tesseract-recognizer).
</Callout>

The input may be a `ScaleDpImage`, an `OffscreenCanvas` or `ImageData`. An
unknown `preset` throws `RangeError` from the constructor; see
[the preset list](/docs/stages/recognise/paddle-text-recognizer#language-presets).

## Parameters

| Parameter | Type | Default | Meaning |
| --- | --- | --- | --- |
| `preset` | `'v6-small'` \| `'v6-medium'` \| `'v6-tiny'` \| `'v5-latin-mobile'` \| … (14 total) | `'v6-small'` | Language/script pairing. Detection and recognition share the download. |
| `scoreThreshold` | `number` 0–1 | `0` | Drop regions below this confidence. 0 keeps everything. |
